virtual vs Override

virtual : 부모 클래스 함수 앞에 붙는 한정자
자식 클래스에서 재정의될 것으로
예상되는 함수 앞에 작성합니다.

해당 키워드가 붙은 함수는 실행 위치가
런타임 과정에서 결정됩니다.

Override : 자식이 부모 클래스의
함수를 재정의할 때 사용하는 연산자

public virtual void Awake() { }

public override void Awake() {}

abstract : 부모 클래스 함수 앞에 붙는 한정자
abstract 함수를 1개라도 가지고 있는 클래스는
abstract class로 설계됩니다.

함수에 대한 구현 ({}) 을 하지 않고
함수에 대한 정의 (;)를 진행할 수 있습니다.
그리고 이 함수를 부모로 가지는 자식 클래스는
반드시 해당 값을 override 해야 합니다.
--> 이유) 구현 코드에 대한 통일감
             (부모의 형태로 자식의 클래스를 생성하고
              같은 이름의 함수를 호출해 기능을
             돌려쓰는 다형성 기법)

sealed : 상속에 대한 제한
